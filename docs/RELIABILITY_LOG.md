## Known Remaining Limitations (Tracked Honestly)

1. **DOCX Charts & SmartArt (`word/charts/chart*.xml`, `word/diagrams/data*.xml`):** Now transparently reported in `stats.unsupportedParts` rather than silently omitted, but not yet rewritten in place.
2. **Flutter & iOS Usage-Site Coverage:** `Musify` (`26.9%`) and `IceCubesApp` (`8.6%` without SPM `Packages/` paths) still miss some null-aware (`context.l10n?.foo`) and SwiftUI `LocalizedStringKey` indirect call patterns.
3. **Astro Monorepo Auto-Discovery:** `withastro/starlight` puts locales in `packages/starlight/translations/` rather than root `src/content/i18n/`, requiring explicit `paths.locales` in `.wraith/config.json`.
4. **Live Crowdin / Phrase API Credentials:** XLIFF 2.0/1.2 round-trip import/export and `human-verified` QE protection are verified deterministically in CI; live HTTP push/pull against Crowdin/Phrase cloud APIs requires user-supplied API tokens.
